# 🌭 Paraiba Hot Dog

Plataforma digital da **Paraiba Hot Dog**, franquia de cachorro-quente de Brasília.

O projeto reúne, em uma única plataforma, recursos voltados tanto para os **clientes** quanto para a **gestão das lojas**, proporcionando uma experiência integrada para consulta de produtos, pedidos e gerenciamento da operação.

## 🏪 Sobre o projeto

A plataforma oferece recursos como:

* 🌭 Cardápio e informações sobre os produtos
* 📍 Informações e localização das lojas
* 🛒 Realização e acompanhamento de pedidos
* 📦 Gerenciamento de pedidos pela loja
* 🏪 Recursos de apoio à operação das unidades
* 👤 Funcionalidades voltadas aos clientes e à equipe da loja

## 🧩 Estrutura

O projeto é organizado em diferentes repositórios, de acordo com suas responsabilidades:

* 🎨 **Frontend** — interface e experiência dos usuários
* ⚙️ **Backend** — APIs, regras de negócio e integração com os serviços da plataforma
* 📚 **Docs** — documentação, requisitos e organização do projeto

## 🚀 Desenvolvimento

Este projeto é desenvolvido de forma colaborativa, utilizando GitHub para controle de versão, gerenciamento de Issues, Pull Requests e planejamento das atividades.

As Issues e Pull Requests seguem templates e padrões compartilhados pela organização para manter o desenvolvimento consistente entre os diferentes repositórios.
